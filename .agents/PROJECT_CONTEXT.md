# Project Context

## Project Name

Project Atlas

---

# Vision

Project Atlas is an AI-native, multi-tenant SaaS platform built as a reference implementation of modern backend engineering.

The project demonstrates how to build a production-grade software platform using Ruby on Rails, FastAPI, Vue.js, Docker, Kubernetes, Terraform, PostgreSQL, Redis, and AI services.

The project is intended to be both production-ready and educational.

---

# Objectives

Project Atlas exists to demonstrate:

- Modern Rails architecture
- Domain-Driven Design (DDD)
- Clean Architecture principles
- REST API design
- AI-assisted software development
- Cloud-native infrastructure
- Production engineering practices

- RFC 9457
- Multi-tenant architecture
- UUID primary keys

# Engineering Philosophy

Always prefer:

- Simplicity
- Readability
- Maintainability
- Explicitness

Avoid:

- Premature optimization
- Hidden magic
- Duplicate code
- Large classes

# AI Agent Expectations

AI agents should:

- Read documentation before writing code.
- Follow existing architecture.
- Reuse existing implementations.
- Keep commits focused.
- Update documentation alongside code.

AI agents should not:

- Introduce unnecessary dependencies.
- Ignore engineering principles.
- Bypass architectural decisions.
- Create duplicate implementations.
